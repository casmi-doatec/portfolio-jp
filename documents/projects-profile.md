**カテゴリ:** 業務基幹システム
**技術スタック:** Next.js / TypeScript / Prisma / WebSocket / PWA / PostgreSQL / Google Cloud / Python

- WebSocketによるリアルタイム予約状況の同期

- 本部・加盟店・スタッフの多階層権限管理
- 店舗別・期間別のレポート自動集計
- ブラックリスト検知・重複予約防止ロジック
- PWA対応による現場スマホ運用の最適化
- 一括取得から必要最小限のAPI取得方式へ刷新し、読み込み速度と安定性を大幅に改善
